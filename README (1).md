# Gestion de Recrutement - Carrieri

## 📋 Fonctionnalités

### 🎯 Gestion des Missions
- ✅ **Création de missions** - Ajouter de nouvelles missions avec description, score minimum et créateur
- ✅ **Liste des missions** - Visualiser toutes les missions avec statistiques
- ✅ **Modification de missions** - Éditer les détails des missions existantes
- ✅ **Suppression de missions** - Supprimer des missions avec confirmation

### 📊 Gestion des Soumissions (Rendu)
- ✅ **Soumission de code** - Les candidats peuvent soumettre leur code pour une mission
- ✅ **Liste des soumissions** - Tableau interactif avec filtres et recherche
- ✅ **Évaluation automatique** - Notation automatique des soumissions
- ✅ **Statistiques détaillées** - Tableaux de bord avec graphiques
- ✅ **Export des données** - Export CSV et rapports HTML

### 📈 Tableau de Bord Statistiques
- ✅ **Statistiques globales** - Taux de réussite, score moyen, top performeur
- ✅ **Graphiques interactifs** - Distribution des scores, performance par mission
- ✅ **Métriques détaillées** - Temps d'évaluation, nombre de soumissions
- ✅ **Visualisation temporelle** - Timeline des soumissions

📝 Utilisation
Pour les administrateurs
Ajouter une mission - Via le bouton "Nouvelle Mission"

Consulter les soumissions - Via "Historique des Soumissions"

Analyser les statistiques - Via "Statistiques" dans la liste des soumissions

Pour les candidats
Sélectionner une mission - Double-clic sur une mission

Soumettre du code - Via le formulaire de soumission

Consulter les résultats - Dans la liste des soumissions

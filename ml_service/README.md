# 🤖 SERVICE ML - GÉNÉRATEUR D'OFFRES IA

Ce dossier contient tous les fichiers Python nécessaires pour entraîner et utiliser le modèle IA.

## 📁 Structure

```
ml_service/
├── README.md                    ← Vous êtes ici
├── requirements.txt             ← Dépendances Python
├── training_data.csv            ← Vos données d'entraînement
├── prepare_data.py              ← Préparation des données
├── train_model.py               ← Entraînement du modèle
├── test_generation.py           ← Test du modèle
├── api_service.py               ← API Flask pour Java
└── model_offres_final/          ← Modèle entraîné (après training)
```

## 🚀 GUIDE D'UTILISATION RAPIDE

### Étape 1 : Installation
```bash
pip install -r requirements.txt
```

### Étape 2 : Préparer les données
```bash
python prepare_data.py
```

### Étape 3 : Entraîner le modèle
```bash
python train_model.py
```

### Étape 4 : Tester
```bash
python test_generation.py
```

### Étape 5 : Lancer l'API
```bash
python api_service.py
```
